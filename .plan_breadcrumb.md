# Plan: fix(claude-runner): workflow selection should be label-based, not title-prefix inference (#494)

## Files to modify

- `crates/claude-runner/src/policy.rs`
- `crates/claude-runner/src/workflow.rs`

## Approach

`select_workflow()` in `workflow.rs` currently falls back to heuristic title-prefix inference when no label matches `policy.workflows`. The fix removes that inference block entirely. `RepoPolicy` in `policy.rs` gets two new fields: `default_workflow: Option<String>` (fallback when no label matches) and `workflow_templates: Vec<WorkflowTemplate>` (so the policy path can resolve custom template names just like the route-based `RunnerConfig` does). `select_workflow()` is updated to resolve template names against both custom and built-in templates, and use `policy.default_workflow.as_deref().unwrap_or("feature")` as the final fallback instead of the inferred name. All three `select_workflow` call sites in `orchestrator.rs` are unaffected because the function signature stays the same.
